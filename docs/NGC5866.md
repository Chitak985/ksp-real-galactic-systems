# NGC 5866 generated galaxy

NGC 5866 now uses the shared `lenticular` template and saved galaxy catalog. Its body identifier remains `NGC5866`; its generated file is `RealGalacticSystems/Systems/ngc_5866.cfg`. `far` is `None`, so it stays in the base Systems folder. The deleted manual file is not restored, and the obsolete manual-position registration is removed. The importer exclusion is lifted only for this galaxy.

The original `RealGalacticSystems/Cache/NGC5866.bin` mesh cache is removed so Kopernicus can regenerate it for the new invisible Jool-template barycenter. Other caches, galaxies, root bodies and physical configurations are untouched.

## Data and geometry

The saved SIMBAD/VizieR response is `data/galaxy_sources/ngc_5866.json`. SIMBAD resolves NGC 5866 as **M 102**, with the same J2000 position as the former manual body, a measured redshift of 0.002528 and B/V/K photometry. The nearby catalog query returns no match. Its generic `S` morphology label is replaced by the reviewed lenticular classification, rather than being interpreted as a spiral automatically.

[Topal et al. (2016), Table 1](https://doi.org/10.1093/mnras/stw2257) tabulate distance 15.3 Mpc, optical diameters 4.7 by 1.9 arcmin, position angle 127 degrees and disk inclination 89 degrees. The outer, bulge-dominated axis ratio is not treated as the thin disk's inclination. The adopted distance and estimated stellar mass `log10(M/M_sun) = 11.2` are also tabulated in [the 2012 globular-cluster population study](https://doi.org/10.1088/0004-6256/144/6/164). The stellar mass is a game point-mass proxy; it is not a measured central black-hole mass or a full dark-halo mass.

The reviewed replacement fields are retained in `data/ngc5866_adoptions.json`. Disk inclination and appearance refinements are saved in the galaxy catalog's `rendering_overrides`. The default lenticular template supplies a smooth disk and prominent bulge without spiral arms. This galaxy enables a thin, absorbing dust midplane to approximate its conspicuous edge-on dust lane. Star samples, dust density, vertical thickness, colors and exposure are display estimates, noted in the description. No global template is changed.

At the adopted distance the optical diameter is about 20.9 kpc. The generated positioning orbit remains frozen, hidden, circular and Sun-parented; the core SOI is capped at 100 pc. The measured near-side ambiguity, detailed dust distribution and real light profile are not resolved by this model.

## Rebuild

```powershell
python -B rebuild_galaxies.py --galaxy ngc_5866
python -B rebuild_galaxies.py --check
python -B fetch_galaxies.py "NGC 5866" --offline --refresh --overrides data/ngc5866_adoptions.json
```

The ordinary rebuild uses saved measurements and templates without network access. The refresh command replays the reviewed adoption fields; appearance refinements remain in the catalog.
